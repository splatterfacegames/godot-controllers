Every controller, one input layer.

godot-controllers is a Godot 4.7 addon for input management and normalization. Xbox, PlayStation, Nintendo and generic pads, and keyboard and mouse, all map onto one layout. Each player gets their own devices, actions, bindings and glyphs.

Try it in your browser.

Plug in up to four controllers, or use the keyboard. Press Start or the confirm button on a pad, or Enter on the keyboard, to join. Browsers only report a pad after you press one of its buttons. Rebind actions, move the deadzone sliders, press Y / Triangle / X or R to rumble, and add the scripted bot to watch virtual input go through the same pipeline.

The Web build uses Godot's Compatibility renderer and the browser Gamepad API. Some browsers don't support rumble. Open the demo full-page.

What it does.

One canonical layout

Face buttons by position, triggers as 0–1 axes, sticks as 2D values, plus d-pad, start/select/home, touchpad and paddles. Families come from the USB vendor id, including the ids browsers embed in gamepad names.

Nintendo A/B, handled

Bind menus to confirm and cancel. Each game chooses whether confirm follows the button's position or its "A" label.

Players and joining

Automatic, press-to-join or manual. Keyboard and mouse is its own device. A pad that disconnects goes back to its player when it reconnects.

Actions in categories

Button, axis and 2D actions in categories you switch on and off per player. The press that closes a menu never leaks into gameplay.

Rebinding

Rebinding waits for release, then captures the next input and shapes it to the action. Conflicts swap, replace, reject or are allowed. Bindings are saved per player and per family.

Signal processing

Radial, axial and hybrid deadzones with inner and outer edges, response curves, and trigger thresholds with hysteresis.

Frame-accurate

Taps shorter than a tick are latched. Tick in _physics_process, _process, or manually at your game's original rate. Queries cover press, release, hold, double-tap, repeat and long-press.

Glyphs and rumble

Prompts follow each player's device live, using Kenney's Input Prompts. Rumble is per player, and gyro and light-bar hooks work where Godot exposes them.

Virtual input

Labelled virtual devices and a recorder let tests and demo drivers inject input through the same pipeline, and say so on screen.

Install.

Copy addons/controllers into your project and enable Controllers under Project Settings → Plugins.

Controllers.declare_action(&"jump", CtlAction.Type.BUTTON, &"gameplay", "Jump", {
	"kbm": [{"key": KEY_SPACE}],
	"gamepad": [{"pad": &"face_south"}],
})

func _physics_process(_delta):
	var p := Controllers.player(0)
	if p.is_just_pressed(&"jump"):
		jump()
